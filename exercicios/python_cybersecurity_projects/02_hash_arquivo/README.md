# 02 Hash Arquivo

Calcula SHA-256 para checagem de integridade.

## Requisitos
- Python 3.10 ou superior
- Dependências no `requirements.txt`

## Instalação
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Execução
```bash
python main.py caminho/do/arquivo
```

## Estrutura
- `main.py`: código-fonte
- `requirements.txt`: dependências
- `README.md`: documentação e instruções

## Uso responsável
Projeto educacional de segurança defensiva. Use apenas em sistemas, arquivos e redes próprios ou autorizados.
