# Python Cybersecurity Advanced Labs

Cinco projetos independentes em Python para estudo de Segurança da Informação:

1. `01_mini_siem` — ingestão de eventos, regras de detecção e alertas em SQLite.
2. `02_detector_phishing` — análise heurística de mensagens `.eml` e `.txt`.
3. `03_sistema_mfa` — autenticação local com senha e TOTP.
4. `04_scanner_dependencias` — auditoria de dependências com pip-audit.
5. `05_detector_anomalias` — detecção não supervisionada com Isolation Forest.

## Requisitos gerais
- Python 3.10 ou superior.
- Recomenda-se criar um ambiente virtual separado por projeto.
- Cada pasta contém seu próprio `README.md` e `requirements.txt`.

## Como começar
Entre na pasta do projeto desejado, crie e ative um ambiente virtual e instale as dependências listadas no respectivo `requirements.txt`.

## Aviso
Material educacional. Execute análises somente em arquivos, sistemas, contas e redes que você possui ou tem autorização para testar. Os dados de demonstração são sintéticos. Não publique segredos, QR Codes MFA, logs pessoais ou arquivos confidenciais.
